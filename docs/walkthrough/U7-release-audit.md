## Scientific limits and deliberately deferred ideas

Primary-standard table verification, professor questions and independent local
laboratory validation remain open. Internal holdout is not external validation;
10 mix IDs is a project guard, and repeated holdout tuning weakens evidence.
Slump is heuristic; no accuracy/confidence band is established. SCM strength,
general optimization, automatic yield balancing, environmental scores,
cross-validation and dataset column/unit inference remain deferred. The current
stable CSV schema and pure model interface are retained.
